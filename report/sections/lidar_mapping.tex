\section{LiDAR results and map acquisition}
Figure~\ref{fig:lidar} shows scans nearest each recording's midpoint.
For 720 original beam indices, $\alpha_i=\alpha_{\min}+i\Delta\alpha$,
$x_i=r_i\cos\alpha_i$, and $y_i=r_i\sin\alpha_i$.
Removing infinite returns leaves 456, 458, and 488 points; finite positive ranges remain because sensor limits were not logged.
Wall-like segments appear to have different orientations in these local sensor frames.
